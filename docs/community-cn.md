# 简体中文社区版维护说明

本项目从官方稳定版本移植中文界面。官方 Git 历史保留在分叉中，中文修改位于默认的 `cn` 分支；`upstream` 指向官方仓库。

## 当前范围

当前构建为 `0.1.7-zh-test.1`，基于官方 v0.1.7。中文化覆盖 Web 界面、Electron 原生菜单、语言选择与持久化、会话及原生右键菜单、浏览器批注和动态辅助提示。移动端没有完成中文版本的验收，Windows 和 Linux 没有完成本分叉的打包验收。

登录页面使用官方英文界面，继续连接官方 Clerk / T3 Connect 服务。构建时使用上游 `.env.example` 内的公开标识；不需要服务端密钥，也不在仓库内保存用户登录状态。

中文桌面构建使用独立的名称、应用标识和数据目录，并关闭指向官方发行渠道的自动更新，以免后续更新覆盖中文版本。这些设置沿用当前测试构建，不会把旧中文数据自动迁回官方版。

## 构建与固定交付

在仓库根目录安装依赖，然后执行：

```bash
vp i
sh scripts/build-cn.sh
```

默认构建版本为 `0.1.7-zh-test.1`，也可显式指定已经适配的构建号：

```bash
sh scripts/build-cn.sh 0.1.7-zh-test.1
```

构建脚本使用当前源码，不会自动拉取或更换官方基础。默认交付目录是 `release-cn`，可通过 `T3CODE_CN_OUTPUT_DIR` 指定。

每次成功构建后会覆盖固定名称的 `T3-Code-CN-arm64.dmg`，并更新 `SHA256SUMS.txt` 与 `VERSION`。临时打包产物在退出时清理；构建失败不会覆盖上一次成功的安装包。本地无需保存多份旧 DMG 或 ZIP，历史源码和公开版本由 Git / Releases 留存。

原生资源监控助手默认从仓库内对应源码构建。维护者在本机复用已核对版本和散列的助手时可使用上游已有的复用选项；不能假定其他机器已经具有该缓存。

安装包通过签名完整性检查与 DMG 校验。采用本地证书签名，没有 Apple 公证。

本次缺少项目要求的 T3 Browser panel 工具，尚未完成新版本的逐项 UI 点击验收；以前版本的界面走查不能代替本次验收。OAuth 回跳、T3 Connect 远程连接、多提供商真实模型调用及完整公司业务仍待验证。移动端、Windows 和 Linux 未在本轮打包验收。

网页引用只有内部 ID、没有来源网址时，界面使用来源占位提示，无法还原可点击的链接。用户消息、代码、路径、模型名和原始诊断保留原样。
