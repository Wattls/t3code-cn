# 简体中文社区版维护说明

本项目从官方稳定版本移植中文界面。官方 Git 历史保留在分叉中，中文修改位于默认的 `cn` 分支；`upstream` 指向官方仓库。

## 当前范围

当前基于官方 v0.1.6。中文化覆盖 Web 界面、Electron 原生菜单、语言选择与持久化、会话及原生右键菜单。移动端没有完成中文版本的验收，Windows 和 Linux 没有完成本分叉的打包验收。

登录页面使用官方英文界面，继续连接官方 Clerk / T3 Connect 服务。构建时使用上游 `.env.example` 内的公开标识；不需要服务端密钥，也不在仓库内保存用户登录状态。

中文桌面构建使用独立的名称、应用标识和数据目录，并关闭指向官方发行渠道的自动更新，以免后续更新覆盖中文版本。这些设置沿用当前测试构建，不会把旧中文数据自动迁回官方版。

## 构建与固定交付

在仓库根目录安装依赖，然后执行：

```bash
vp i
sh scripts/build-cn.sh
```

默认构建版本为 `0.1.6-zh-test.7`，可在适配新的版本后显式指定构建号：

```bash
sh scripts/build-cn.sh 0.1.6-zh-test.8
```

构建脚本使用当前源码，不会自动拉取或更换官方基础。默认交付目录是 `release-cn`，可通过 `T3CODE_CN_OUTPUT_DIR` 指定。

每次成功构建后会覆盖固定名称的 `T3-Code-CN-arm64.dmg`，并更新 `SHA256SUMS.txt` 与 `VERSION`。临时打包产物在退出时清理；构建失败不会覆盖上一次成功的安装包。本地无需保存多份旧 DMG 或 ZIP，历史源码和公开版本由 Git / Releases 留存。

原生资源监控助手默认从仓库内对应源码构建。维护者在本机复用已核对版本和散列的助手时可使用上游已有的复用选项；不能假定其他机器已经具有该缓存。

## 已有验证

- 主要中文界面、语言切换与持久化、原生菜单和右键菜单曾在本机桌面 App 中检查。
- 历史消息读取、提供商状态和模型目录、独立仓库的 Git 行为曾在隔离副本中检查。
- 本次登录配置修复的 5 个相关测试文件、共 33 项测试通过，已检查最终安装包内的 Web 与桌面公开登录配置。
- 交付包通过 `codesign --verify --deep --strict` 和 `hdiutil verify`。

这些检查不代表全平台、全提供商或整库测试已经通过。当前登录修复包的本人登录、浏览器 OAuth 回跳和 T3 Connect 远程连接尚待验证；发布时作为测试版本说明。两版使用相同回调协议，macOS 的默认处理程序可能影响登录回到哪个 App。

首次公开前运行了 `vp run check:changed HEAD --concurrency 2`：格式、lint 和 452 个客户端文件的 React Compiler 检查通过。检查发现的语言上下文与独立应用标识测试夹具已对齐，相关复核为 71 项通过、1 项失败；剩余失败是 `GuestPage.browser.test.tsx` 的自动滚动用例，尚未解决。Web 与桌面的独立类型检查通过。

综合检查仍未全部通过：移动端和官网依赖不完整，导致完整依赖分析与跨全部包的类型检查无法完成。不要将这些范围报告为通过，也不要据此宣称 Windows、Linux、移动端或访客滚动已经验收。本版本以 prerelease 发布。

## 后续维护

跟进官方稳定版本，保留其新增功能和修复，只移植相关语言修改。更新后运行受影响的检查并验证实际界面；不要把类型检查成功当作登录或模型调用成功。

确认官方稳定 macOS 包已经接入简体中文界面和可用的语言选择入口后，暂停重复移植。仅有计划、讨论、PR、翻译文件或其他社区分叉不触发暂停。
